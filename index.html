Edita Anterior, Nuevos y Actualizado por plan. El Actual se calcula.

Cada plan tiene tres campos editables: Anterior (casos al cierre pasado), Nuevos (casos creados este período) y Actualizado (casos que recibieron mantenimiento este período). Actual = Anterior + Nuevos. Al iniciar un período nuevo, usa Cerrar período para pasar el Actual a Anterior. Todo se guarda automáticamente en este navegador; Reiniciar vuelve a los datos del archivo, CSV descarga el detalle e Imprimir / PDF exporta el reporte completo.
